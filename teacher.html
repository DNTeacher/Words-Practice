      설정

      GitHub 열쇠 (처음 한 번)

      이 컴퓨터의 이 브라우저에만 저장돼요. 열쇠는 Words-Practice(학생 페이지)에 올리고 Words-Books(단어장 정리본)를 읽는 데만 쓰여요. 이미 쓰고 있는 열쇠를 적어 두셨다면 그대로 붙여넣어도 돼요.

      1. GitHub 열쇠 만들기 화면을 엽니다 (dnteacher 계정으로 로그인).
      2. Token name: 단어장 앱 · Expiration: 원하는 기간 (예: 1년)
      3. Repository access: Only select repositories → Words-Practice와 Words-Books 두 개 모두 고르기
      4. Permissions → Repository permissions → Contents 를 Read and write 로
      5. 맨 아래 Generate token → 나온 열쇠(github_pat_로 시작)를 복사해 아래에 붙여넣기
