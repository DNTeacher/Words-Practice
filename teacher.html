    GitHub 열쇠 (처음 한 번)

    이 노트북 브라우저에만 저장돼요. 열쇠는 Words-Practice 저장소에 파일을 올리는 데만 쓰여요.

    1. GitHub 열쇠 만들기 화면을 엽니다 (dnteacher 계정으로 로그인).
    2. Token name: 단어장 앱 · Expiration: 원하는 기간 (예: 1년)
    3. Repository access: Only select repositories → Words-Practice
    4. Permissions → Repository permissions → Contents 를 Read and write 로
    5. 맨 아래 Generate token → 나온 열쇠(github_pat_로 시작)를 복사해 아래에 붙여넣기
